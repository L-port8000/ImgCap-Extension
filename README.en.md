# ImgCap Extension

## Features

- Batch extract images from a URL list in the current tab or from iframe items such as [My Tools](https://site.l-ituki8000.workers.dev/tools/iframe.html)
- Automatically scroll to load and download all images on the page that are larger than a specified size

- [Chrome Browser](https://github.com/L-port8000/ImgCap-Extension/tree/chrome)
- [Firefox Browser](https://github.com/L-port8000/ImgCap-Extension/tree/firefox)
